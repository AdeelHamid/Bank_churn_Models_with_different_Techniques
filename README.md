# Bank Customer Churn Prediction (Machine Learning Model Training) with Different Techniques
We have trained a model using XGBoost and CatBoost Algorithm by fully analyzing the dataset taking from the competition of KAGGLE.
The dataset is taken from Kaggle competition and we analysed and cleaned the data. Performed feature engineering.

Now our model predicts the customers churn from then bank with 90% of confidence.
